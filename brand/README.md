# Noirr Curator — brand assets

Noirr Curator finds, evaluates, imports, and organizes media. The public app
name is **Noirr Curator**; the short in-app name is **Curator**; the visual
lockup is `noirr_ curator`.

`icon-master.svg` is the canonical icon geometry. The lowercase c and uppercase
U share a baseline, with the c reaching roughly two-thirds of the U and the red
dash sitting beneath the c. Generated PNGs live in `export/`.

The repository, binary, bundle identifier, URL scheme, service-discovery name,
configuration keys, API paths, and data directories remain `monarr` for
compatibility. A public rename must not silently change those contracts.
