## 1. Daily navigation

Give Activity one destination on desktop and phone. Promote Discover onto the phone tab bar. Keep Library, Discover, Wanted, Activity, and More for this cleanup. Calendar, administrative pages, and display preferences stay reachable from More. Keep the existing desktop destinations until there is a separate reason to change them. Preserve old /imports bookmarks by routing to Activity scoped to imports. Do not label Wanted as Requests. Wanted tracks acquisition gaps. Household requests require their own attribution and lifecycle. The next product increments are household requests and library-aware discovery. The existing Discover UI knows catalog membership, and newly added titles can open in Library. A monitored library record alone does not prove that the requested movie, episode, or edition is available to play. ## 3. Why fewer items should ask for help

The pipeline contract describes environmental holds, who owns terminal facts, and how an import ends. Its signed-off later decisions change how unattended file ambiguity is handled. Current automatic imports decide each file. Rejected payloads, exhausted attempts and unsatisfied wants can produce replacement grabs. The hourly pass recovers or ends waiting work. Environmental holds carry reasons and retry automatically once the condition clears. Show the cause, elapsed time and an available retry time. Reserve Needs attention for an actionable choice such as explicit import approval, a missing library folder, a changed storage mount, or files deliberately left undecided in a manual import. A failed attempt with a replacement already underway belongs in History and can link to the replacement. Keep historic cleanup approval distinct from authorizing a live import. ## 5. Decisions for the owner

The preview assumes that historical delivery receipts remain inspectable on demand and that the staged Runner copy wizard stays outside daily navigation. Removing the receipt storage or staged-copy APIs would require a separate decision about existing operators and pending work. Check real installations for unfinished obligations before deleting data or retiring those workflows. The unmounted wizard needs an explicit owner decision only if someone still depends on staged Runner copies through the web. Setup and migration can follow the household requests and discovery work. The existing Dev naming convention in the repository agent guide should be updated with the eventual approved navigation.
