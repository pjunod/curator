  • 0001Name Monarr, GPL-3.0, port 7676; amended: ghcr.io images, pjunod/monarr
  • 0002One media_items table + kind; files↔episodes n:m; Wantable abstraction
  • 0003v3 compat as /sonarr + /radarr URL-base personalities, translation-only
  • 0004SQLite only (modernc, WAL, single writer)
  • 0005Migration by filesystem adoption; *arr DB import is a stretch
  • 0006Books as a third media kind (ebooks + audiobooks)
  • 0007–8Multi-host execution: leased job queue on SQLite; Postgres only for clustered mode
  • 0009–10Root folders carry a kind; scan proposes, adoption is bulk work with a confidence bar
  • 0011Series metadata is a chain: TheTVDB when keyed, TVmaze free, TMDB always
  • 0012Manual entries: a record no provider backs, episodes read off the disk
  • 0013–14Quality is measured, not inferred; profiles are floor + target + upgrades ("Any" retired)
  • 0015Discovery is a read-only browse surface: TMDB always, Trakt when keyed, nothing stored
  • 0016Air times from TVmaze's show-level schedule, composed to UTC per date at read time — absent beats guessed
  • 0017–18Audiobook format routing and multipart import; ebook and audiobook coexist as independent editions of one book work
